# 医院挂号小程序原型

这是一个功能完整的医院挂号小程序原型，提供了直观的用户界面和流畅的交互体验。

## 功能特性

### 1. 首页
- **科室选择**：8个热门科室（内科、外科、儿科、妇产科、骨科、眼科、口腔科、皮肤科）
- **搜索功能**：可搜索科室和医生
- **快速入口**：我的预约、就诊记录、电子就诊卡、检查报告
- **底部导航**：首页、预约、服务、我的

### 2. 医生列表页
- **医生卡片**：显示医生头像、姓名、职称、擅长领域
- **评分系统**：显示医生评分和服务人数
- **职称筛选**：可按主任医师、副主任医师、主治医师筛选
- **价格显示**：清晰展示挂号费用

### 3. 预约时间选择页
- **日期选择**：未来5天的日期选择
- **时间段选择**：上午和下午的时间段
- **实时显示**：已约满的时间段会显示提示
- **费用预览**：底部显示挂号费用

### 4. 预约确认页
- **预约成功提示**：带动画的成功图标
- **详细信息**：科室、医生、时间、地点、预约号码
- **就诊二维码**：用于现场签到
- **快捷操作**：返回首页或查看预约

### 5. 我的预约页
- **预约状态**：待就诊、已完成、已取消
- **预约详情**：包含医生信息、时间、地点
- **操作按钮**：取消预约、查看详情、再次预约等

## 技术特点

### 设计亮点
- **现代化UI**：采用卡片式设计，清晰的视觉层次
- **渐变配色**：科室图标采用渐变色，提升视觉美感
- **阴影效果**：适度的阴影增强立体感
- **响应式布局**：适配不同屏幕尺寸

### 交互体验
- **平滑过渡**：页面切换和按钮交互都有平滑动画
- **触摸友好**：按钮大小适合触摸操作
- **滑动返回**：支持从左向右滑动返回上一页
- **键盘支持**：ESC键可返回上一页
- **防重复点击**：避免快速点击导致的问题

### 移动端优化
- **视口设置**：适配移动设备显示
- **触摸优化**：所有交互元素都考虑了触摸操作
- **滚动优化**：自定义滚动条样式
- **加载动画**：页面加载时的渐显效果

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 推荐使用Chrome或Safari浏览器查看
3. 可以按F12打开开发者工具，切换到移动设备视图查看效果

## 页面流程

```
首页
 ├─ 选择科室 → 医生列表页
 │              ├─ 选择医生 → 预约时间页
 │                            ├─ 选择时间 → 预约确认页
 │                                          └─ 返回首页 / 查看预约
 └─ 我的预约 → 我的预约页
                └─ 查看预约详情 / 取消预约
```

```
/workspace/
```
