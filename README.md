# 医院挂号小程序原型

这是一个医院挂号小程序的原型设计，展示了完整的预约挂号流程和用户界面。

## 功能特性

### 主要页面

1. **首页**
   - 快速操作入口（预约挂号、我的预约、个人中心、联系我们）
   - 今日可预约统计信息
   - 热门科室快捷入口

2. **科室选择页面**
   - 科室列表展示
   - 搜索功能
   - 显示每个科室的可预约号源数量

3. **医生选择页面**
   - 医生列表展示（包含头像、职称、擅长、评分等信息）
   - 筛选功能（全部、今日可约、专家）
   - 显示医生可预约时间段和价格

4. **时间选择页面**
   - 日期选择器
   - 时间段选择（显示可预约和已满状态）
   - 预约信息摘要

5. **确认页面**
   - 完整的预约信息确认
   - 患者信息展示
   - 费用信息
   - 温馨提示

6. **我的预约页面**
   - 待就诊、已完成、已取消分类
   - 预约详情展示
   - 取消预约功能

## 设计特点

- **现代化UI设计**：采用渐变色和卡片式布局，界面美观大方
- **响应式设计**：适配移动端和桌面端
- **交互流畅**：页面切换动画和悬停效果
- **用户体验优化**：清晰的信息层级和操作流程

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件即可查看原型
2. 所有交互功能都已实现，可以完整体验预约流程
3. 点击各个按钮和卡片可以切换页面和选择选项

## 文件结构

```
├── index.html      # 主HTML文件，包含所有页面结构
├── styles.css      # 样式文件，包含所有UI样式
├── script.js       # JavaScript文件，包含交互逻辑
└── README.md       # 说明文档
```

## 技术栈

- HTML5
- CSS3（使用Flexbox和Grid布局）
- 原生JavaScript（无依赖框架）

## 页面流程

1. 首页 → 点击"预约挂号"或热门科室
2. 科室选择 → 选择科室
3. 医生选择 → 选择医生
4. 时间选择 → 选择日期和时间段
5. 确认页面 → 确认信息并支付
6. 成功提示 → 预约完成

## 注意事项

- 这是一个原型设计，数据为模拟数据
- 实际开发时需要连接后端API获取真实数据
- 支付功能需要集成第三方支付接口
- 用户认证和个人信息管理功能需要后端支持
