# 医院挂号小程序原型

这是一个完整的医院挂号小程序原型，展示了从选择科室到完成预约的完整流程。

## 功能特性

### 主要功能
- 🏥 **科室选择** - 浏览并选择不同科室
- 👨‍⚕️ **医生选择** - 查看医生信息、职称和评价
- 📅 **时间预约** - 选择就诊日期和时间段
- ✅ **预约确认** - 填写就诊人信息并确认预约
- 📋 **预约管理** - 查看和管理已预约记录

### 页面结构
1. **首页** - 展示医院信息和快速入口
2. **科室选择页** - 列出所有可用科室
3. **医生列表页** - 显示选定科室的医生信息
4. **时间选择页** - 选择就诊日期和时间段
5. **确认预约页** - 填写信息并提交预约
6. **我的预约页** - 查看所有预约记录

## 使用方法

### 直接打开
1. 在浏览器中打开 `index.html` 文件
2. 无需任何服务器或构建工具，可直接运行

### 功能演示流程
1. 点击首页的"预约挂号"按钮
2. 选择科室（如：内科、外科、儿科等）
3. 选择医生（查看医生信息和评价）
4. 选择就诊日期和时间段
5. 填写就诊人姓名和联系电话
6. 提交预约
7. 在"我的预约"中查看预约记录

## 技术特点

- **纯前端实现** - 使用 HTML、CSS、JavaScript 构建，无需后端
- **响应式设计** - 适配移动端和桌面端
- **本地存储** - 使用 localStorage 保存预约数据
- **现代化UI** - 渐变色彩、卡片式设计、流畅动画
- **交互友好** - 清晰的导航、状态反馈、表单验证

## 注意事项

- 这是一个**原型演示**，预约数据仅保存在浏览器本地
- 实际项目中需要连接后端API进行数据存储
- 手机号码验证使用简单正则，实际应用需要更严格的验证
- 时间段可用性为模拟数据，实际应通过后端接口获取
