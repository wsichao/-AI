# 医院挂号小程序原型

一个完整的医院预约挂号小程序交互原型，使用纯 HTML/CSS/JavaScript 实现，无需安装任何依赖。

## 📱 功能模块

### 1. 首页
- 医院信息展示
- Banner 轮播图
- 快捷功能入口（预约挂号、我的预约、报告查询、在线问诊）
- 热门科室展示
- 推荐医生列表
- 公告通知栏

### 2. 科室选择
- 科室分类导航（常用科室、内科系统、外科系统、专科门诊、中医科室、体检中心）
- 科室搜索功能
- 科室列表展示

### 3. 医生列表
- 医生卡片展示
- 筛选功能（综合排序、职称、日期）
- 医生详细信息（职称、经验、擅长、排班）
- 挂号费用显示

### 4. 时间选择
- 选中医生信息展示
- 7天日期选择
- 上午/下午时段选择
- 号源余量显示

### 5. 预约确认
- 就诊信息汇总
- 就诊人选择（支持多就诊人）
- 病情描述输入
- 温馨提示
- 服务协议确认
- 支付功能

### 6. 预约成功
- 成功状态展示
- 就诊二维码
- 预约详情
- 就诊指南

### 7. 我的预约
- 预约状态筛选（全部、待就诊、已完成、已取消）
- 预约卡片列表
- 取消预约/查看详情/评价医生/再次预约

### 8. 个人中心
- 用户信息展示
- 快捷统计（待就诊、已完成、收藏医生、待评价）
- 功能菜单（就诊人管理、就诊记录、电子发票、医保绑定、就诊指南、客服中心、设置）

## 🚀 快速开始

### 方法一：直接打开
```bash
# 直接用浏览器打开 index.html 文件
open hospital-booking-prototype/index.html
```

### 方法二：使用本地服务器
```bash
# 使用 Python 3
cd hospital-booking-prototype
python -m http.server 8080

# 然后在浏览器访问 http://localhost:8080
```

### 方法三：使用 VS Code Live Server
1. 安装 Live Server 扩展
2. 右键点击 `index.html`
3. 选择 "Open with Live Server"

## 🎨 设计特点

- **现代UI设计**：采用流行的渐变色和圆角设计
- **仿真手机框架**：375x812 iPhone X 尺寸展示
- **完整交互流程**：从首页到预约成功的完整流程
- **响应式交互**：悬停效果、点击反馈、页面切换动画
- **Font Awesome 图标**：丰富的医疗相关图标

## 🛠️ 技术栈

- HTML5
- CSS3（Flexbox、Grid、渐变、动画）
- Vanilla JavaScript（ES6+）
- Font Awesome 6.4.0

## 📝 使用说明

1. **首页导航**：点击快捷功能或热门科室进入预约流程
2. **选择科室**：在科室页面选择需要就诊的科室
3. **选择医生**：查看医生信息，选择合适的医生
4. **选择时间**：选择就诊日期和时间段
5. **确认预约**：填写就诊人信息，确认预约
6. **支付完成**：完成支付后查看预约详情
